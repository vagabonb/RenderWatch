RENDER WATCH 1.2.3 — исправление шкал вентиляторов

Полоса оборотов больше не меняет диапазон по текущей скорости.
При наличии тахометра полоса рассчитывается по RPM, а не по сигналу управления.
Для обычных вентиляторов ПК ориентир шкалы составляет 3000 об/мин;
для определённых программой ноутбуков и распознанных помп — 6000 об/мин.
Это ориентиры отображения, а не измеренные заводские максимумы.
Подсказка при наведении на полосу объясняет используемую шкалу.

Пример для шкалы 3000: 2600 об/мин = 86,67%; 3000 об/мин = 100%.
Показания датчиков и управление скоростью вентиляторов не изменялись.
Новые зависимости и фоновые задачи не добавлялись.

Проверка: 42 проверки шкалы и 243 проверки отрисовки WPF прошли.
В полном запуске доступных тестов: 51 успешный, 3 сбоя старых проверок строк
с повреждённой кодировкой; живые аппаратные тесты не выполнялись.
Подробный отчёт и данные симуляции приложены к результатам работы в Codex.
